# SpendSeal 控制台（主人单页）

`index.html` — 单文件、**无 CDN、无后端**（链上读写为手写最小 ABI 编解码；舞台大屏的二维码生成库 qrcode-generator 1.4.4 已内嵌进页面，MIT 许可，现场断网也能开）。配置写死：金库地址、USDC、链 ID 与演示地址簿，舞台上不手输地址。

## 功能

- 只读区（打开即有数据，无需连钱包）：护照余额/剩余额度、今日额度进度条、限额、白名单（含链上实时状态）、付款流水（PaymentExecuted）、拒绝审计区（PaymentRejected）；
- 写操作（需连接主人钱包，MetaMask 等）：存入（approve + 入账合并为一次点击流程）、提回、保存限额、白名单加入/移除、拒绝上链开关、**熔断**（红色大按钮 + 二次确认，明示不可恢复）；
- 护照 #1/#2 一键切换（演示/测试隔离）；每 4 秒自动刷新，顶栏有手动「↻ 刷新」按钮（舞台上付款后点一下立即看到流水，不用等轮询）。

## 舞台大屏模式（2026-11-21 加入，纯呈现层）

- 按键（焦点不在输入框时）：`B` 大屏开/关 · `E` 结尾投票卡 · `S` 左侧「无护照钱包」模拟掏空动画（跑完后再按一次 S 复位待机）。熔断等写操作不在大屏里——按 B 退出后操作。
- 大屏内容：超大余额/今日额度进度条、最新一笔付款的交易二维码（观众扫码自验；无付款时为金库地址码）、本场真实拦截计数（次数+金额，来自链上 PaymentRejected 事件，**要求该护照已打开拒绝上链审计开关**）、左侧模拟对比区（全程标注「模拟演示」）、按 E 切换的全屏投票卡（金库二维码；投票方式以现场公布为准、卡面不写死）。
- 音效：WebAudio 现场合成，成功 = 盖章声+叮、拒绝 = 低沉 buzz；付款成功时大屏中央盖「PAID · 已验签」印章动画（`window.StampEffect.trigger()` 是预留接口，将来实体印章/物理按钮调同一函数）。浏览器自动播放策略：必须先在页面点过一次才有声。
- **计数口径**：统计「本页面打开以来新出现的链上事件」，首次链上扫描完成后建立基线、历史事件不计。演示期间**不要刷新本页**，否则本场计数清零（链上数据本身不受影响）。切换护照会重置计数与基线。

## 本地打开

```bash
cd web && python3 -m http.server 8080
# 浏览器开 http://localhost:8080/  （正式演示连钱包时请导入主人私钥到 MetaMask，
# 网络切到 Monad Testnet 10143）
```

URL 参数：`?passport=2` 默认护照；`?rpc=<url>` 覆盖 RPC（本地 anvil fork 联调用）。

## 已知约束（如实记录）

- **Monad 公共 RPC 限制 `eth_getLogs` 单次最多 100 个区块**（实测错误 -32614）。页面已内置分块扫描器：首次加载回看约 6,000 个区块（约 40 分钟），之后用水位线增量扫描。若将来要看更久远的流水，应换带索引的 RPC/浏览器 API，而不是加大窗口硬扫。
- 白名单列表由「已知地址簿 + 6,000 区块内 PayeeAdded 事件」拼出；更早加入的陌生地址可能不显示（其白名单状态本身在链上有效，只是列表枚举不到）。演示地址簿已覆盖全部演示角色。

## 验证

`seller/test/console.mjs`（在 seller 目录运行 `node test/console.mjs`）会用无头 Chromium 加载本页（RPC 指向 anvil 的测试网 fork），断言链上护照 #1 的余额、今日已付、日限额、单笔限额与白名单状态符合预期，并截图存 `web/test/console.png`。依赖：anvil fork 跑在 :8545、本页静态服务跑在 :8080。断言的具体数值随链上状态变化，需要与新部署的护照状态保持一致。
