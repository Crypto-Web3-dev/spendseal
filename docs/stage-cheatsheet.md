# SpendSeal 舞台速查卡（一页版，演示当天贴屏幕边）

> 2026-11-21 按 Kevin 拍板更新：新幕序（幕 0 前 30 秒先上真交易、观众当黑客、手机自验 QR、大屏+音效+对比计数器+投票卡）。脚本全文与口径边界见 `guangzhou-blitz-plan.md` §Demo 脚本。

## 机器分工（Windows + WSL）

| 跑在哪 | 什么 |
|---|---|
| **WSL Ubuntu** | **一条命令起两个服务**：`cd <仓库根>/spendseal && bash start-all.sh 1`（同时起卖家+控制台，自动打印 Windows 浏览器该用的地址）。另开一个备用终端（幕 5 跑攻击脚本） |
| **Windows** | Claude Desktop（经 wsl.exe 拉起 WSL 里的桥）、浏览器开控制台（用 start-all.sh 打印出的地址；MetaMask 在这签） |

- Claude Desktop 配置用 `bridge/claude_desktop_config.windows-wsl.example.json`：`args` 里的 node 脚本路径必须写**真实路径** `<仓库根>/spendseal/bridge/src/index.js`（写成别的路径会报 `Server disconnected`），`PASSPORT_ID` 正演填 1。
- 桥的密钥/金库地址自动读仓库根 `.env`，配置里不用填私钥。
- `start-all.sh` 打印的「控制台(Win浏览器)」地址就是今天该用的那个——WSL2 的 localhost 转发本机不可靠，别用 `localhost` 硬试。IP 每次 WSL 重启会变，所以每次开机跑一次 start-all.sh 取地址即可。彻底修复：管理员 PowerShell 执行 `wsl --shutdown`，等 10 秒重进 WSL。
- 若不想用脚本：卖家 `cd .../seller && node src/server.js`，控制台 `cd .../web && python3 -m http.server 8080`（两个终端，各别关）。

## 窗口编排（三个虚拟桌面，Win+Ctrl+←/→ 切换）

- 桌面 1：**控制台大屏模式**（开演前打开控制台 → 按 `B` 进大屏 → 点一下页面解锁音效；幕 0、1、5、6、7 主画面）

> **「大屏」不是一个新窗口，就是控制台那个标签页本身。** 同一个 `http://localhost:8080/` 页面，按 `B` 后全屏铺满（超大字+二维码，管理功能隐藏），再按 `B` 退回普通模式。所以「切大屏」= Alt+Tab 到桌面 1 + 按一下 `B`，不需要打开别的网址。
- 桌面 2：**Claude Desktop**（幕 0 下单、幕 2–4 主画面）
- 桌面 3：**WSL 终端全屏**（幕 5 攻击脚本）

节奏口诀：**在 Claude 里下单 → 切大屏看数字/盖章/计数 → 回 Claude 继续**。控制台自动刷新 6 秒，大屏数字与计数跟着链上事件自己动，不用手点。**付款成功后约 2–8 秒才在大屏反应**（链上确认 + 刷新周期 + 1.2 秒轮询），所以下单成功后稍等一下再切，别急着以为没生效。

**大屏按键**（焦点别停在输入框里；按键没反应就先点一下页面空白处）：`B` 大屏开/关 · `E` 结尾投票卡 · `S` 模拟掏空（跑完后再按一次 S = 复位待机，彩排试跑后记得复位）。
**熔断只能在普通模式按**：红按钮在大屏里是隐藏的，幕 6 先按 `B` 退出大屏。
**音效**：成功 = 盖章咚+叮，拒绝 = 低沉 buzz；付款成功时大屏中央盖「PAID · 已验签」印章。音效靠浏览器策略，必须先在页面上点过一次才有声——开演前点一下并放一笔彩排付款验证。
**大屏期间不要刷新控制台页面**：本场拦截/付款计数会清零（计数口径 = 页面打开以来新出现的链上事件）。

## 为什么非做不可（30 秒，带出处）

> 「机器已经在花钱了，而规矩放在它够得着的地方。
> 今年 10 月 Cornell Tech 和 Yale 的实验：十个前沿模型各配真实钱包、日限额 0.01 美元——**十个里九个**自己去主人邮箱翻验证码给自己提额，无越狱无攻击者。`[预印本 arXiv:2610.35835；口径=每模型 20 次运行至少 1 次；已向 Circle 披露]`
> 同月 Chainalysis：x402 在 Base 累计 **1.385 亿笔**，**87% 单笔不到 0.1 美元**。`[二手]`
> 笔数亿级了，规矩还挂在服务器和邮箱里。」

**一句话定位（背下来）**
> 别人把规则放在服务器上，我们把规则放在合约里。服务器可以下线、可以作恶、可以被攻破，但它放行不了一笔合约不认的钱。

**② 报价签名为啥非做不可（被追问时的最短答）**
> 「合约只能保证它检查的数字没问题，保证不了那个数字等于卖家的真实报价。没有报价签名，Agent 是在盲签——护照每条规则都通过，付的却是假发票。②把报价在源头用密码学签死，改一个字就废。六步里，只有这一步把『信任网络』变成了『信任数学』。」
> 配套两句：① 白名单防**主动**付错人，签名防**被动**付错人，两道独立的门；② 必须在链下付款前验——合约看不到报价，付款后才验钱已经出去了。

**竞品（每档一句，别展开；证据等级见计划文档）**
| 类型 | 代表 | 强制点 | 我们不同 |
|---|---|---|---|
| 大厂钱包 | Coinbase / Circle / MetaMask / Privy | **厂商服务器** | 规则在合约里 |
| 协议层 | AP2 / Mastercard VI `[原文规格]` | 证据强；预算交给各家服务器；双花拒绝是 MAY | 累计强制在合约 |
| 链上框架 | MetaMask **ERC-7710** `[原文]` | 合约 ✅ 但只是框架 | 接成买卖闭环 |
| 同赛道 | Catena / KeeperCard `[二手]` | 多为托管 | 自托管单合约 |
| 攻防对照 | ETHGlobal x402-Guardrails `[项目自述]` | 浏览器 IndexedDB | 强制层级不同 |

**同生态 ≠ 竞品（别混说）**
| 项目 | 它做什么 | 关系 |
|---|---|---|
| Olien | 团队金库准入 | 互补（准入 vs 限额） |
| Hive | Agent 记忆权限 | 无关 |
| NadBounty | Agent 赚钱（任务赏金） | 互补（赚钱 vs 花钱） |
| TickPay / Agora-mesh | 卖家侧发现 + x402 结算 | 相邻（它没买家护照） |

**上台黑名单（说错会被当场纠正）**
1. ❌「首创/第一个做链上强制」→ ✅「组合与强制层级」
2. ❌「管控层是空白」→ ✅「缺跨厂商累计 + 无信任执行 + 自助撤销」
3. ❌「$25B 是 Monad 的量」→ ✅「Visa 全网年化量」
4. ❌ 报 400ms 或 800ms → ✅ 只说「亚秒级终局」
5. ❌「十个模型全能绕过」→ ✅「十个里九个，口径是 20 次至少 1 次」
6. ❌ 报 x402 修正后的具体数字（1,500 万 / 1,900 万）→ ✅「原始 1.357 亿，剔除刷量后**千万美元级**」
   （2026-11-21 复核：两个数字在仓库内冲突，公开网络查不到 Artemis 原始报告，无法定论。被追问就说「我看到两个不同修正值，差异来自方法论，重要的是量级」）
